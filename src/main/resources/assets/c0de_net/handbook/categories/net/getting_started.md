Programs that use the library include it with INCLUDE c0de\_net/http. Its type and functions start with the library name, like c0de\_net/http/HTTP\_GET.

Every program, also without the INCLUDE, has the constant `C0DE_NET_VERSION` with the version of c0de net as text, like "0.2.0".
