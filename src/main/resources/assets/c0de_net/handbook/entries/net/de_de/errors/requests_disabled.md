Code 1002, `c0de_net/http/REQUESTS_DISABLED`: Der Client des Spielers, der den Prozess ausführt, sendet keine Anfragen.

Dieser Spieler hat `allowRequests=false` in `config/c0de_net-client.properties` gesetzt.
